75 Sekhiyā · правила для тренировки

Термин на пали буквально означает «чтобы тренироваться в…». В этом разделе Винаи 75 правил, которые делятся на четыре категории:

1. Этикет ношения одеяний и этикет поведения в населённой местности;
2. Этикет в принятии и поедании пищи с подаяний;
3. Этикет при обучении кого-либо Дхамме;
4. Этикет при облегчении нужды.

Сумма этих правил составляет лицо саманер и бхиккху, а значит и облик Сангхи в целом. Известны истории о том, как бханте Сарипутта вдохновился манерами бханте Ассаджи и решил вступить в общину, а также о том, как король Ашока обратился в буддизм под впечатлением от манер молодого саманеры.

Общая формула

Если правило нарушается из неуважения, это влечёт проступок дукката. Повторяющийся контекст возникновения правил (пребывание Будды в Саваттхи, проступки «группы шестерых», ропот мирян и упреки Будды) опущен; сохранены все уникальные истории, точные формулировки, подробные разъяснения и полные списки исключений.

Об аккуратном ношении одеяния Parimaṇala-vaggo pahamo

Правило «Я буду носить нижнее одеяние ровно со всех сторон».

Пояснение Нижнее одеяние следует носить ровно со всех сторон, закрывая пупок и колени. Если из неуважения носит его свисающим спереди или сзади — дукката.

Нет проступка непреднамеренно; по забывчивости; по незнанию; болен; во время опасности; безумен; первонарушитель.

Правило «Я буду носить верхнее одеяние ровно со всех сторон».

Пояснение Верхнее одеяние следует носить ровно, выравнивая оба края. Если из неуважения носит свисающим спереди или сзади — дукката.

Нет проступка непреднамеренно; по забывчивости; по незнанию; болен; во время опасности; безумен; первонарушитель.

Пояснение Следует идти с опущенным взором, смотря вперёд лишь на длину ярма. Если из неуважения озирается по сторонам — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; во время опасности; безумен; первонарушитель.

Пояснение Сфокусировав внимание на чаше, следует принимать подаяние. Если из неуважения, смотря по сторонам, не замечает, когда накладывают пищу — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; во время опасности; безумен; первонарушитель.

Правило «Я буду принимать подаяние с соусом в надлежащей пропорции».

Пояснение Есть два вида соуса: из бобов мунг и из чёрного маша. Следует принимать соус в надлежащей пропорции, который можно взять рукой. Если из неуважения принимает очень много соуса — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; в отношении жидких соусов; если получено от родственников, от пригласивших, ради блага другого, за собственные средства; во время опасности; безумен; первонарушитель.

Правило «Я буду принимать подаяние вровень с краями чаши».

Пояснение Следует принимать подаяние вровень с краями чаши. Если из неуважения принимает, сложенное горой — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; во время опасности; безумен; первонарушитель.

khambhakatavaggo tatiyo niṭṭhito · Окончен третий раздел — об упирании в бока и далее.
О почтительном отношении к пище Sakkacca-vaggo catuttho

Правило «Я буду есть подаяние почтительно».

Пояснение Следует есть почтительно. Если из неуважения ест непочтительно, словно не желая есть — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; во время опасности; безумен; первонарушитель.

Правило «Сфокусировав внимание на чаше, я буду есть подаяние».

Пояснение Сфокусировав внимание на чаше, следует есть. Если из неуважения, смотря по сторонам, не замечает, что подкладывают еду — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; во время опасности; безумен; первонарушитель.

Правило «Я буду есть подаяние последовательно».

Пояснение Следует есть последовательно. Если из неуважения ест, выбирая кусочки то тут, то там — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; если выбирает, чтобы дать другим; перекладывая в чужую посуду; в отношении гарниров; во время опасности; безумен; первонарушитель.

Правило «Я буду есть подаяние с соусом в надлежащей пропорции».

Пояснение Следует есть с соусом в надлежащей пропорции. Если из неуважения ест очень много соуса — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; в отношении жидких соусов; от родственников, от пригласивших, за собственные средства; во время опасности; безумен; первонарушитель.

Правило «Я не буду есть подаяние, приминая его сверху».

Пояснение Не следует есть, приминая пищу сверху. Если из неуважения ест приминая — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; если ест, сгребая вместе и приминая небольшие остатки еды; во время опасности; безумен; первонарушитель.

Правило «Я не буду прикрывать соус или гарнир рисом, желая получить больше».

Пояснение Не следует прикрывать соус или гарнир рисом из желания получить больше. Если из неуважения прикрывает — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; если хозяева дают еду уже прикрытой; если сделано не из желания получить больше; во время опасности; безумен; первонарушитель.

Контекст Монахи выпрашивали соус и рис, вызвав ропот мирян. Позже больные монахи сказали, что им это помогало, и Будда разрешил это больным.

Пояснение Не больному не следует выпрашивать и есть. Если из неуважения выпрашивает — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; больным бхиккху; от родственников; от пригласивших; ради блага другого; за собственные средства; во время опасности; безумен; первонарушитель.

Правило «Я не буду с намерением найти изъян смотреть в чужую чашу».

Пояснение Не следует смотреть с намерением найти изъян. Если из неуважения смотрит — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; если смотрит с мыслью «я дам» или «я велю дать»; если без намерения найти изъян; во время опасности; безумен; первонарушитель.

Правило «Я не буду делать слишком большой кусок пищи».

Пояснение Не следует делать слишком большой кусок. Если из неуважения делает большой — дукката.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; в отношении закусок, плодов и фруктов, соусов; в случае опасности; безумен; первонарушитель.

Нет проступка ненамеренно; по забывчивости; по незнанию; болен; в отношении закусок, плодов и фруктов, соусов; в случае опасности; безумен; первонарушитель.
